# Day 22 — API Recon: Developing a Backend-First Mindset

## 1. The Paradigm Shift: Backend over UI
- **Actions:** Shifted recon focus from traditional web visible elements (pages, forms) to API structural elements (logic, methods, versions).
- **Outcome:** Established UI as mere consumer while backend structure represents true attack surface.

---

## 2. The Consultant's "Five Questions"
- **Actions:** Developed high-fidelity attack strategy framework answering:
  - Authentication: Identity proofing (JWT, OAuth, Cookies).
  - Roles: Actor identification (Admin, Partner, Internal).
  - Object References: Data indexing (UUIDs vs. Numeric IDs).
  - Versioning: Legacy path discovery (/v1 vs /v2/beta).
  - Environments: Asset mapping (Staging, Dev, Test).
- **Outcome:** Created systematic intelligence foundation for targeted testing.

---

## 3. Layered Intelligence Gathering
- **Actions:** Structured recon through five disciplined layers: Surface Discovery → Endpoint Categorization → Parameter Analysis → Role Mapping → Trust Boundary Mapping.
- **Outcome:** Built progressive intelligence pipeline eliminating random testing.

---

## 4. Impact on Downstream Testing
- **Actions:** Mapped recon outputs to specific test types: BOLA from object patterns, BFLA from function routes, OAuth from auth mechanism analysis.
- **Outcome:** Transformed reconnaissance into direct feeder for structured exploitation workflows.

---

## Summary
- **Actions:** Established professional recon as antidote to random testing, converting blind guessing into targeted exploitation through structured intelligence gathering.
